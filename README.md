# CSA Operating Hub

GRPS Community & Student Affairs resource center for the CSA Leadership Team and CSA staff.

The GitHub Pages site contains Home, resource search and department filters, ten department profiles, and Leadership. Leadership includes six operating expectations, three Leading the GRPS Way presentations, a searchable 47-entry case library, and a case-selectable facilitator guide with copy support. The SOP Center opens the existing written-process library directly.

## Update

Edit `index.html` for layout and behavior, and `data.json` for resources, departments, and Leadership content. The official GRPS logo is embedded in the HTML. No framework, build, or paid hosting is required. Pages deploys from `main` at the repository root.

Run `node verify.mjs` to check resource navigation, filters, case-to-guide selection, Leadership content, and duplicate-hub exclusions. After changing the data, update the data-request version in `index.html` to avoid a stale cached resource list.

## Document access

Document links open the individual file at its existing Google Drive, document host, or publisher location. Only three reports reviewed for public sharing are included: the 2025–26 attendance report, the TFI report, and the July 2025 MTSS planning document with user-approved cover photos. The full Health Advocacy report is excluded because school-level small medical counts could identify scholars. Supplied case PDFs, licensed readings, draft evaluations, and Word documents remain at their existing locations. Existing file access and publisher terms still apply. The hub no longer sends staff to a second CSA homepage to find Leadership content.

## Verification limits

Automated checks do not prove access to every restricted document or replace testing in iPhone Safari. Confirm file permissions with an intended CSA reader before broad distribution.

## Positive department highlights

`data.json` contains dated highlights with source links, reporting periods, department connections, and limits on interpretation. Highlights appear only in the relevant department profiles; they are excluded from the homepage. Add only verified results. Distinguish activity from outcomes, counts from unique people, and shared district results from department attribution. Do not publish unapproved draft findings or identifiable scholar data. Current seed highlights use the supplied 2025–26 chronic absenteeism end-of-year report, the final Ignite 2025 evaluation, and the official GRPS Class of 2025 graduation-rate release.
